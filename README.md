## What This Does

This is an agent that gives fashion advice as well as creating captions. A user 
is able to ask the agent for a specific clothing they are looking for. They are
able to get advice on whether to buy certain items. They can also automatically
create a caption once an item has been bought.

---

## Tool Inventory

### `search_listings`

**What it does:**

Takes in a user's general description and finds similar items within the dataset.

**Inputs:** 

Takes in three parameters. The first is 'description' which is a string and is 
required. This description can include a brand but is not needed. The second parameter 
is 'size' which is also a string and is a optional parameter. It is not case sensitive 
and can be passed as 'None' to skip. The third parameter is 'max_price' which is a
float and is also an optional parameter. It can be passed by passing 'None'.
  
**Returns:**

Returns a list of dictionaries. each dict has the following fields:
id, title, description, category, style_tags (list), size, condition, 
price (float), colors (list), brand (str or None), platform. 

**When it has nothing:**

If nothing matches a empty list will will be returned.

### `suggest_outfit`

**What it does:**

Suggests outfits based on a user's wardrobe and a new potiential clothing item.

**Inputs:**

Takes in two parameters. The first is a listing dictionary which contains
the item the user is considering to buy. The second parameter is a 
dictionary with the key 'items'. These items are clothing items a user
owns. This dictionary may be empty.

**Returns:**

Returns a string of a potiential outfit based on the information it was given. 

**When it has nothing:**

If the dictionary that contains a user's clothing items is empty it will give
general styling advice.

### `create_fit_card`

**What it does:**

Creates a caption based on the chosen outfit.

**Inputs:**

Takes in two required parameters. The first is 'outfit' which is a string from 
suggest_outfit(). The second parameter is 'new_item' which is the listing dict 
for the item.

**Returns:**

A string containing 2 - 4 sentences representing a caption.

**When it has nothing:**

Returns a descriptive message.

---

## Planning Loop

**Branch rule:**

If the string 'description is emtpy in search listing then stop session and ask 
user for a proper explanation of the item that want. 
If the dictionary containing a user's clothing items is empty put a message in
the session asking for more information on their clothing items. Once items have
been given run suggest_outfits() and pass result onto create_fit_card.

**Where it lives:** `agent.py::run_agent`

**How the query is parsed:** Regex (`re` module in `_parse_query`), extracting price ceilings (e.g. `under $30`), size filters (e.g. `size M`), and cleaning conversational phrases to isolate description keywords.

**What moves through the session:**
1. `query` (str) & `wardrobe` (dict) initialize the session via `new_session()`.
2. `parsed` (dict): Extracted `description`, `size`, and `max_price`.
3. `search_results` (list[dict]): Matching listing dictionaries returned by `search_listings()`.
4. `selected_item` (dict): The top listing dictionary chosen from `search_results` (or `error` set if empty).
5. `outfit_suggestion` (str): Styling recommendations returned by `suggest_outfit(selected_item, wardrobe)`.
6. `fit_card` (str): Final 2–4 sentence caption generated by `create_fit_card(outfit_suggestion, selected_item)`.

## How I Used AI

**Moment 1**

- *What I asked for:* I was stuck on `run_agent()` in `agent.py`, so I pasted in the TODO comments and asked Claude to help me implement it. I specifically wanted it to parse the user's query with regex and handle the case where `search_listings` finds nothing.
- *What came back:* It gave me a working loop that called the tools one after another, but it just passed values straight from one call into the next. Nothing was saved to or read from `session`. And when the search came up empty, it set `session["error"] = "No results found"`, which doesn't tell the user anything useful.
- *What I changed:* I rewrote it so every tool's result gets written to `session` and then read back out for the next call. That way I can actually see what state the agent is in at each step. I also changed the empty-search branch to look at what was searched for and suggest something concrete, like raising the price ceiling or using broader search terms, instead of just hitting a dead end.

**Moment 2**

- *What I asked for:* I wanted to know what makes a fit caption feel real and worth posting on Depop or Instagram, and how I could turn that into acceptance criteria I could actually check for `create_fit_card`.
- *What came back:* Claude broke it down into a few things: start with a hook that grabs attention, mention details you can feel (texture, wash, fabric, something unusual about the piece), keep it short at 2 to 4 sentences, and work the price and platform in naturally.
- *What I changed:* I turned that advice into two criteria in `criteria.md`. Criterion 4 requires specific details like color, texture, or pattern, and Criterion 5 requires an opening hook. Then I rewrote the prompt in `create_fit_card()` in `tools.py` to spell out those same requirements, including a hard limit of 2 to 4 sentences.
